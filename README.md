# Creative Computing · IADT Open Day 2026 (Revision 2)

A complete **21-slide, self-contained offline-capable web presentation** in 16:9.

## Present

Open `index.html` in Chrome, Safari, Edge or Firefox with the `assets` folder alongside it. Use **← →** or space to navigate, **F** for fullscreen, **O** for the slide overview and **N** for notes. Internet is not needed for the slides, but external links to OnShow/IADT require it.
